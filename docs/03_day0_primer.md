# Day 0 primer: can you do these? (30 minutes, before Day 1)

You do not need to be an expert. You need to recognise these. If one is new to you, search it, try it, and bring a question.

## SQL
1. Write a query that returns the number of orders per table number.
2. What does `JOIN` do? Write a join of `orders` and `order_items`.
3. What is the difference between `WHERE` and `HAVING`?

## Python
4. What is a list? What is a dictionary? Make one of each about a menu item.
5. What does `import pandas as pd` let you do? Read a CSV and show the first 5 rows.

## Data formats
6. Write a small JSON document for a complaint with a nested field.
7. What is the difference between a CSV and an Excel file?

## The web
8. What happens when your app calls an API? Name three things that can go wrong.

## Tools
9. Clone a repo, make a change, commit, and push.
10. What is an environment variable, and why do we keep passwords in `.env`?

If you cannot answer 1, 2, 5, 9 and 10 yet, ask your instructor for a short catch-up before Day 1.
